## 何が入っているか

| 何 | どこ | 手本にする的 |
|---|---|---|
| 視界 3 ボタンの定義（直近一週間・合意・論争と、それぞれ 3 状態のラベル） | `page.jsx` の `VIEW_BUTTONS` | 視界ボタンの画面側 |
| 視界ごとの絞り込みの式（賛成率 0.7 以上かつ 3 票以上、など）と、期間ごとの点数 | `page.jsx` の `score`・`counts` と、その下の絞り込み | 視界の集計（API 側） |
| 画面の構成（見出し・ファクトの一覧と追加・ワードクラウド・タグの一覧と投票・タグの投稿・並び替え） | `page.jsx` の `return` 以下 | ページ表示とワードクラウド |
| 見た目（配色・配置・ワードクラウドの語の大きさ） | `globals.css` | ページ表示とワードクラウド |
| 見本のデータ（ページ・ファクト・タグ） | `page.jsx` の `SEED_ENTITIES` | 手元で画面を確かめる時の種 |

## 使い方の注意

- 仕様の正本は `metagmo_spec.md`。試作と食い違ったら仕様に従い、食い違いを報告する。
- 試作はブラウザの中だけで動く（保存しない・サーバーが無い）。今の計画は Worker がページを返す形（`spec.md` §7）なので、**コードをそのまま持ち込まず、式・構成・見た目を写す**。
- 見本のデータの出典 URL には `example.com` の仮の値が混じっている。本番のデータには使わない。
